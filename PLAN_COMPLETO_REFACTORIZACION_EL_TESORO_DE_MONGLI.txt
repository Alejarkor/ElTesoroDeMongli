0. ESTADO BASE
==============

Proyecto Unity:
- Repo: Alejarkor/ElTesoroDeMongli
- Unity: 2021.3.4f1
- Escena activa: Assets/Scenes/MONGLICLIENT.unity
- Networking: Mirror
- Transporte WebGL disponible: SimpleWebTransport
- Target: navegador/WebGL, incluyendo iOS y Android

API:
- Repo: sergio4anso/ElTesoroDeMongliAPI
- Stack: PHP procedural + MySQL/MariaDB
- DB local: eltesorodemongli
- Tablas detectadas: users, access_tokens
- Endpoints principales: register, login, validation, get_users, update_users

Regla arquitectónica:
- API/DB: login, registro, tokens, perfil, progreso, persistencia puntual.
- Mirror/WSS: realtime, jugadores conectados, spawn, movimiento, animaciones.
- WebGL client: UI, input, presentación, interpolación, conexión API y WebSocket.
- La DB no debe usarse como bus principal de movimiento realtime.
